# Contributing

Issues and pull requests are welcome. Before opening an issue, avoid including real financial data, account numbers, credentials, or other sensitive personal information.

## Development

1. Install Node.js 22 or later and npm.
2. Run `npm ci`.
3. Start the app with `npm run dev`.
4. Before submitting a pull request, run `npm run lint` and `npm run build`.

Describe the user-visible change and how you verified it. For UI changes, include the browser and viewport sizes you checked. There is currently no automated unit-test script.
